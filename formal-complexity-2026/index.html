Bird’s-eye view

The goal of this course is to acquaint you with the study of formal linguistic complexity. Specifically, we will cover complexity classes of languages, focusing on regular, context-free, context-sensitive, recursive, and recursively enumerable languages. We’ll explore each class of languages in terms of: (a) the formal grammars that generate languages in that class; and (b) the abstract machines that recognize languages in the class. Along the way, we’ll discuss hypotheses about the complexity of natural language (e.g., the subregular hypothesis in phonology, and the hypothesis that natural language syntax is mildly context-sensitive), as well as some grammar formalisms which have been proposed to capture these hypotheses.

Assignments and grading

Grading

Your work in this course will consist of seven (7) problem sets—sometimes based on assigned readings—as well as a take-home final exam. The problem sets will be due every other week (see the calendar). Each assignment will be available on this site and will typically feature problems selected from Partee et al. (1993) / Partee et al. (1990). Please either turn in a physical copy of your responses the beginning of the class on which the assignment is due, or upload them to Canvas before class starts.

The problem sets will be graded on a 100-point scale. Each problem set will provide a precise breakdown of how points are allocated.

These will account for 70% of your grade, and a take-home final exam, for 30%. The take-home final will be due on December 9th at 5pm. It will be formatted similarly to the assignments, but it will be a little more substantial.

The following grading scale will be used to determine course grades:

93.5 ≤ A ≤ 100 89.5 ≤ A- < 93.5
86.5 ≤ B+ < 89.5 83.5 ≤ B < 86.5 79.5 ≤ B- < 83.5
76.5 ≤ C+ < 79.5 74.5 ≤ C < 76.5 69.5 ≤ C- < 74.5
66.5 ≤ D+ < 69.5 64.5 ≤ D < 66.5 59.5 ≤ D- < 64.5

Collaboration (including with chatbots)

We’ll talk about this in class. Basically:

  • Complete the assignments yourself.
  • If you worked with someone else in the class (or a chatbot) on an assignment, please indicate that you did. If you used a chatbot, include a note with your assignment describing how you used it. Please specify:
    • the prompt you used;
    • the output produced. Please don’t use a chatbot to extract an answer to a problem.

Missed or late work

Late work will be docked 10 points each day it is late. It will not be accepted once it is four days late. If you need an extension, ask for one—just do it prior to the due date.
