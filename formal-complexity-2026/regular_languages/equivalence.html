The equivalence between DFAs and NFAs

It turns out that DFAs and NFAs are equivalent, in the sense that they characterize the same set of languages—the regular languages. Not only that, but it is possible to convert between them: there is a systematic procedure for turning any random DFA into an NFA, as well as one for turning any NFA into a DFA.

To show this, we first provide the following alternative definition of NFAs, which is equivalent to the definition provided by Partee et al. (1990). According to this definition, \(K\), \(Σ\), \(q_{0}\), and \(F\) remain the same, but we present the transition relation slightly differently. Instead of a relation \[Δ ⊆ (K × Σ^{*}) × K\] we define a function \[Δ : K × (Σ ∪ \{ϵ\}) → 2^{K}\] That is, \(Δ\) is defined instead as a function that takes pairs of (1) states, and (2) either elements of the alphabet or \(ϵ\), onto sets of new states.

Note that any such function is equivalent to a relation on \(K × (Σ ∪ \{ϵ\})\) and \(K\): given such a function \(Δ\), you can simply define the relation \[R = \{⟨q, x, q′⟩ ∣ q′ ∈ Δ(q, x)\}\] Note that if \(Δ(q, x) = \varnothing\) for some \(q ∈ K\) and \(x ∈ Σ ∪ \{ϵ\}\), then \(q\) and \(x\) aren’t related to any output state by the relation \(R\).

Meanwhile, if you have a relation \(R ⊆ (K × (Σ ∪ \{ϵ\})) × K\), you can simply define the function \[Δ(q, x) = \{q′ ∈ K ∣ ⟨q, x, q′⟩ ∈ R\}\] Note (correspondingly) that for any \(q ∈ K\) and \(x ∈ Σ ∪ \{ϵ\}\), if \(R\) doesn’t relate \(q\) and \(x\) to any output state, then \(Δ(q, x) = \varnothing\).

Example

Consider the language discussed in the example from earlier. That is, \(L = \{ac, abc, bc\}\). Using the alternative definition, we can provide the following NFA characterizing this language.

  • \(K = \{q_{0}, q_{a}, q_{b}, q_{1}\}\)
  • \(Σ = \{a, b, c\}\)
  • \(F = \{q_{1}\}\)
  • \(Δ(q_{0}, a) = \{q_{a}, q_{b}\}\)
    \(Δ(q_{0}, b) = Δ(q_{0}, c) = \varnothing\)
    \(Δ(q_{0}, ϵ) = \{q_{a}\}\)
    \(Δ(q_{a}, a) = Δ(q_{a}, c) = Δ(q_{a}, ϵ) = \varnothing\)
    \(Δ(q_{a}, b) = \{q_{b}\}\)
    \(Δ(q_{b}, a) = Δ(q_{b}, b) = Δ(q_{b}, ϵ) = \varnothing\)
    \(Δ(q_{b}, c) = \{q_{1}\}\)
    \(Δ(q_{1}, a) = Δ(q_{1}, b) = Δ(q_{1}, c) = Δ(q_{1}, ϵ) = \varnothing\)

Translating DFAs into NFAs

To show that any DFA yields an equivalent NFA, one need only adjust its transition function \(δ\) so that it instead maps pairs of states and words of the alphabet onto sets of output states. Given a word \(w\) and state \(q\), which set of states should the pair \(⟨q, w⟩\) be mapped to? Simply, the one-element set \(\{δ(q, w)\}\), whatever that is.

Thus given a DFA \(⟨K, Σ, δ, q_{0}, F⟩\), we can define the NFA \(⟨K, Σ, Δ, q_{0}, F⟩\), where \(Δ(q, w) = \{δ(q, w)\}\) and \(Δ(q, ϵ) = \varnothing\) (for any \(q\)). In a sense, every DFA already is an NFA; we are just rearranging the definition slightly.

Translating NFAs into DFAs

Going the other direction is more interesting. To do this, there are a couple of definitions it is useful to provide.

\(ϵ\)-only paths

First, we need the notion of a finite \(ϵ\)-only path. Given some NFA, a finite \(ϵ\)-only path can be viewed as a sequence of transitions (possibly of length 0) through its state diagram which only involve \(ϵ\). In the state diagram above, for instance, there is exactly one finite \(ϵ\)-only path of length at least 1 (every state has a length-0 \(ϵ\)-only path to itself): the one from \(q_{0}\) to \(q_{a}\). By contrast, consider the following state diagram:

The NFA represented by this state diagram has three finite \(ϵ\)-only paths of length at least 1 (again, every state has a length-0 \(ϵ\)-only path to itself): one from \(q_{0}\) to \(q_{a}\); one from \(q_{a}\) to \(q_{b}\); and one from \(q_{0}\) to \(q_{b}\). The last path comes from sequencing the first two paths.

More formally, given the transition function \(Δ : K × (Σ ∪ \{ϵ\}) → 2^{K}\), we can define a relation \(Δ_{ϵ} ⊆ K × K\): \[Δ_{ϵ} ≝ \{⟨q, q′⟩ ∣ q′ ∈ Δ(q, ϵ)\}\] That is, \(Δ_{ϵ}\) relates \(q\) to \(q′\) just in case you can reach \(q′\) from \(q\) in one step by reading an \(ϵ\).

Let us now define the notion of composing \(Δ_{ϵ}\) with itself an arbitrary number of times, denoted \(Δ_{ϵ}^{n}\) (where \(n\) is the relevant “arbitrary” number). \[Δ_{ϵ}^{0} ≝ \{⟨q, q⟩ ∣ q ∈ K\}\] \[Δ_{ϵ}^{n+1} ≝ Δ_{ϵ} ∘ Δ_{ϵ}^{n}\] Thus \(Δ_{ϵ}^{0}\) is the identity relation on \(K\); \(Δ_{ϵ}^{1}\) is just \(Δ_{ϵ}\) itself; \(Δ_{ϵ}^{2}\) is \(Δ_{ϵ} ∘ Δ_{ϵ}\) (i.e., \(Δ_{ϵ}\) composed with itself); and so on. Then the following relation, \(Δ_{ϵ}^{*}\), is known as the reflexive transitive closure of the relation \(Δ_{ϵ}\): \[Δ_{ϵ}^{*} ≝ ⋃_{i ∈ ℕ}Δ_{ϵ}^{i}\] In words, \(Δ_{ϵ}^{*}\) relates two states \(q\) and \(q′\) just in case there is a finite (possibly length-0) \(ϵ\)-only path from \(q\) to \(q′\) in the state diagram of the NFA whose transition function is \(Δ\). Because length-0 paths are also allowed, the relation is reflexive; i.e., it relates any state in \(K\) (the set of states) to itself.

ϵ-closure by finite paths

For any set of states \(Q ⊆ K\), we can define its epsilon closure by finite paths \(Ε(Q)\): \[Ε(Q) ≝ \{q′ ∣ \text{there is some } q \text{ in } Q \text{, and } ⟨q, q′⟩ ∈ Δ_{ϵ}^{*}\}\] In words, given any set \(Q\) of states, \(Ε(Q)\) has as an element every state in \(Q\) itself, as well as every state you can get to from a state in \(Q\) via a finite \(ϵ\)-only path.

Consider again the state diagram given just above, and consider the set \(\{q_{0}\}\). Then, \(Ε(\{q_{0}\}) = \{q_{0}, q_{a}, q_{b}\}\); this is the set of states reachable from \(q_{0}\) by some finite \(ϵ\)-only path. Note that if we instead consider the set \(\{q_{0}, q_{a}\}\), we get the same set again: \(Ε(\{q_{0}, q_{a}\}) = \{q_{0}, q_{a}, q_{b}\}\).

The translation

We can now straightforwardly define the translation from an arbitrary NFA to its DFA which accepts the same language. Given an NFA \(⟨K, Σ, Δ, q_{0}, F⟩\), we define the corresponding DFA \(⟨K′, Σ′, δ, q_{0}′, F′⟩\) as follows.

  • \(K′ = 2^{K}\)
  • \(Σ′ = Σ\)
  • \(δ(Q, w) = Ε(⋃_{q ∈ Q}Δ(q, w))\) (where \(w ∈ Σ\))
  • \(q_{0}′ = Ε(\{q_{0}\})\)
  • \(F′ = \{Q ∣ Q ∩ F ≠ \varnothing\}\)

Example

Consider our original example of an NFA again, repeated here.

  • \(K = \{q_{0}, q_{a}, q_{b}, q_{1}\}\)
  • \(Σ = \{a, b, c\}\)
  • \(F = \{q_{1}\}\)
  • \(Δ(q_{0}, a) = \{q_{a}, q_{b}\}\)
    \(Δ(q_{0}, b) = Δ(q_{0}, c) = \varnothing\)
    \(Δ(q_{0}, ϵ) = \{q_{a}\}\)
    \(Δ(q_{a}, a) = Δ(q_{a}, c) = Δ(q_{a}, ϵ) = \varnothing\)
    \(Δ(q_{a}, b) = \{q_{b}\}\)
    \(Δ(q_{b}, a) = Δ(q_{b}, b) = Δ(q_{b}, ϵ) = \varnothing\)
    \(Δ(q_{b}, c) = \{q_{1}\}\)
    \(Δ(q_{1}, a) = Δ(q_{1}, b) = Δ(q_{1}, c) = Δ(q_{1}, ϵ) = \varnothing\)

By using the translation procedure defined above, we obtain the following DFA.

  • \(K′ = 2^{K} =\)
    \(\{\varnothing,\)
    \(\{q_{0}\}, \{q_{a}\}, \{q_{b}\}, \{q_{1}\},\)
    \(\{q_{0}, q_{a}\}, \{q_{0}, q_{b}\}, \{q_{0}, q_{1}\}, \{q_{a}, q_{b}\}, \{q_{a}, q_{1}\}, \{q_{b}, q_{1}\},\)
    \(\{q_{0}, q_{a}, q_{b}\}, \{q_{0}, q_{b}, q_{1}\}, \{q_{0}, q_{a}, q_{1}\}, \{q_{a}, q_{b}, q_{1}\},\)
    \(K\}\)
  • \(Σ′ = \{a, b, c\}\)
  • \(δ(Q, w) = Ε(⋃_{q ∈ Q}Δ(q, w))\)
  • \(q_{0}′ = Ε(\{q_{0}\})\)
  • \(F′ = \{Q ∣ Q ∩ F ≠ \varnothing\} =\)
    \(\{\{q_{1}\}, \{q_{0}, q_{1}\}, \{q_{a}, q_{1}\}, \{q_{b}, q_{1}\}, \{q_{0}, q_{b}, q_{1}\}, \{q_{0}, q_{a}, q_{1}\}, \{q_{a}, q_{b}, q_{1}\}, K\}\)

Note that the state diagram for this DFA displays only states which are reachable from the initial state \(\{q_{0}, q_{a}\}\).
